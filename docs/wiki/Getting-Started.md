# Getting Started with Transfer-Learning-VGG16-Dog-Cat-Classification

## 📋 Prerequisites
- **Python** 3.10+ / **Node.js** 18+
- **Git** & **GitHub CLI**

## ⚡ Quick Start
```bash
# Clone the project repository
git clone https://github.com/Bosaj/Transfer-Learning-VGG16-Dog-Cat-Classification.git
cd Transfer-Learning-VGG16-Dog-Cat-Classification

# Run the evaluation harness
python scripts/eval_harness.py

# Run the QA test suite
python -m pytest tests/test_monitoring_and_qa.py
```
